# Continuare audit — securitate, cache și robots.txt

Actualizează raportul inițial `REPORT_2026_11_13.md`. Blocajele externe de lansare rămân valabile; punctele de mai jos au fost tratate separat.

## Corecții implementate

- `minimatch` 10.2.6, folosit de instrumentele de dezvoltare, a fost înlocuit cu 11.0.8 printr-un override limitat la consumatorii versiunii 10. Nu s-au schimbat dependențele de producție sau regulile ESLint. Scanarea npm curentă raportează **0 vulnerabilități**, față de 10 moderate anterior; aceasta nu garantează absența tuturor problemelor de securitate.
- Configurațiile de document RO și EN sunt separate, cu același design și aceleași URL-uri. Limba HTML nu mai necesită citirea unui antet la fiecare cerere. **60 pagini publice sunt pregenerate**, cu regenerare la 300 secunde. Lista este verificată direct în manifestul Next, nu dedusă din sursă.
- Autentificarea, înregistrarea, recuperarea și resetarea parolei au rute dedicate explicit dinamice în ambele limbi. Răspunsurile lor și pagina contului rămân `private, no-cache, no-store`. În manifest nu există pagini private pregenerate. Prima verificare locală a identificat incompatibilitatea rutelor de autentificare cu fallback-ul ISR; corecția a fost aplicată și verificată înainte de publicare.
- Imaginea de partajare păstrează URL-ul `/opengraph-image` și același conținut. Este servită printr-un handler static, fără dependența implicită de un singur layout rădăcină.
- `Disallow: /admin` bloca și pagina publică `/administrarea-masinii`. Regulile sunt acum delimitate la numele rutelor private, query-uri și subcăi. Este verificat automat că **fiecare URL din sitemap poate fi accesat de crawler**, iar contul, administrația, dosarele și API-urile rămân excluse.

## Google Search Console

Homepage-ul Render consultat înainte de publicare răspundea deja HTTP 200, cu `index, follow`. Blocarea observată pentru o adresă exactă nu poate fi atribuită homepage-ului fără URL-ul inspectat. Pagina `/administrarea-masinii` era însă afectată de regula `/admin`, iar această problemă este corectată.

După publicare, rulează un nou test live pentru URL-ul public pe proprietatea Render și cere indexarea dacă testul permite accesul. Paginile de cont și documentele private nu trebuie indexate. Dacă proprietatea inspectată este încă vechiul domeniu Vercel, aceasta este o proprietate separată; modificarea robots.txt de pe Render nu îi schimbă regulile.

## Limite rămase

Core Web Vitals de teren, conturile Google Analytics/Bing, livrarea reală Gmail/push, finalizarea paginilor juridice și testarea unor build-uri mobile semnate pe dispozitive reale nu sunt certificate de această intervenție. Performanța HTTP live și commit-ul publicat se adaugă mai jos după confirmare.
